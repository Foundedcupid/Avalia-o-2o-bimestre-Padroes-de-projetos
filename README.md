# Padrões de Projeto em Java

| Questão | Padrão | Pacote |
|---|---|---|
| 1 – Monitor de Estoque | Observer | `questao1` |
| 2 – Tarifa de Estacionamento | Strategy | `questao2` |
| 3 – Pedido de Café | Decorator | `questao3` |

## Compilar e executar
```
mkdir out
javac -encoding UTF-8 -d out src/*/*.java
java -cp out questao1.Main
java -cp out questao2.Main
java -cp out questao3.Main
```
